# The Promised Childhood Foundation website

Source for thepromisedchildhood.org, hosted on GitHub Pages.

## What's in this folder

| File or folder | What it is |
|---|---|
| `index.html` | Home page |
| `about.html` | Our story, beliefs, founders, 2026 goals |
| `programs.html` | Firefly Kits, Birthday Wishes, Mentorship, Partnerships |
| `get-involved.html` | Donate, volunteer, partner, share |
| `contact.html` | Contact form, kit requests, FAQ |
| `privacy.html` | Privacy policy (draft — review before launch) |
| `404.html` | "Page not found" page |
| `css/styles.css` | All colors, fonts and layout. Brand colors are at the top. |
| `js/site.js` | Mobile menu and forms. The Formspree address goes on line 6. |
| `images/` | Logo, favicon, link-preview image, and future photos |

## Common edits

- **Change text:** open the page in GitHub, click the pencil icon, edit the words between the tags, then **Commit changes**. The live site updates in about a minute.
- **Turn on a hidden section:** search the page for `SHOW WHEN READY`. Fill in the text, delete the word `hidden`, and remove the `<!--` and `-->` around it if present.
- **Add or replace a photo:** upload it to `images/` with the same file name as the one it replaces.
- **Donations:** the Zeffy form is embedded in the Donate section of `get-involved.html`. If you switch Zeffy forms, replace the link in both places there (search for `zeffy.com`).
- **Connect the forms:** paste your Formspree URL into `js/site.js`, line 6.
